# Credit Card Financial Dashboard using Power BI

##  Project Overview

This project presents an interactive **Credit Card Financial Dashboard** developed using **Power BI, SQL, and CSV data**.

The dashboard analyzes credit card transaction and customer data to provide insights into **revenue, transaction trends, customer behavior, card usage, and key performance indicators (KPIs)**.

The project consists of two interactive dashboards:

1. **Credit Card Revenue Report** – focuses on transaction activity and revenue generation.
2. **Customer Usage & Behaviour Report** – focuses on customer demographics, spending patterns, and credit card usage behaviour.

The objective is to transform raw transaction and customer data into meaningful business insights that can help stakeholders monitor performance and support data-driven decision-making.

---

##  Project Objective

To develop a comprehensive **weekly credit card dashboard** that provides insights into key performance metrics and trends, enabling stakeholders to monitor and analyze credit card operations effectively.

The dashboard helps answer questions such as:

* How much revenue is being generated?
* What are the major sources of revenue?
* Which transaction types contribute the most to revenue?
* How are customers using their credit cards?
* Which customer segments generate higher revenue?
* How do transaction trends change over time?
* Which card categories and customer demographics contribute most to business performance?

## 🔄 Data Flow

The overall data pipeline used in this project is:

**CSV Files → SQL Database → Data Analysis → Power BI → Interactive Dashboard**

### Data Movement Process

#### Step 1: Prepare CSV Files

The raw transaction and customer data was initially available in CSV format.

The data was reviewed and prepared before importing it into the SQL database.

#### Step 2: Create Tables in SQL

Tables were created in the SQL database to store the transaction and customer information.

The database was structured to make the data easier to query, analyze, and connect with Power BI.

#### Step 3: Import CSV Data into SQL

The prepared CSV files were imported into the SQL database.

SQL was then used for data querying and preparation before connecting the data with Power BI.

#### Step 4: Connect SQL with Power BI

The SQL database was connected to Power BI to bring the prepared data into the reporting environment.

#### Step 5: Data Analysis and Visualization

Power BI was used to create:

* KPIs
* Charts
* Tables
* Slicers
* Filters
* Interactive visualizations
* Weekly and quarterly analysis

#### Step 6: Dashboard Development

The processed data was transformed into two interactive dashboards:

**Credit Card Revenue Report**
↓
Financial and transaction analysis

**Customer Usage & Behaviour Report**
↓
Customer segmentation and behaviour analysis
